## Project Overview

The primary objective of this project is to build a regression model to predict home sale prices based on features such as the number of bedrooms, bathrooms, square footage, location, and more. The project follows standard data science practices, including:

- Data cleaning and preprocessing
- Exploratory data analysis (EDA)
- Model training and evaluation
- Insights and recommendations

## Technologies Used

- Python 3.x
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib & Seaborn (for data visualization)
- Scikit-learn (for machine learning)

## Dataset

The dataset includes historical home sales data with various features such as:

- `price`
- `bedrooms`
- `bathrooms`
- `sqft_living`
- `sqft_lot`
- `floors`
- `zipcode`
- `year_built`

> *Note: If the data file is not included due to size or privacy concerns, please refer to the original source or upload your own dataset.*

## Features

- Load and clean the dataset
- Perform exploratory data analysis
- Visualize feature relationships and distributions
- Train regression models (e.g., Linear Regression)
- Evaluate model performance using metrics like RMSE and R²
